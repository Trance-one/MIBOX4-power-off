# Mi Box Power

Минимальное приложение для Android TV 9 (API 28), рассчитанное на управление пультом.

## Что делает

Кнопка открывает штатное системное меню питания Android через AccessibilityService (`GLOBAL_ACTION_POWER_DIALOG`). Затем выключение/сон подтверждается пользователем в системном меню.

Обычное приложение не может гарантированно выполнить полное выключение Android-приставки: системные операции питания защищены привилегированными разрешениями. Поведение и наличие пункта выключения зависят от прошивки Mi Box.

## Первый запуск

1. Откройте приложение на приставке.
2. Нажмите кнопку — откроются настройки специальных возможностей.
3. Найдите `Mi Box Power` и включите службу.
4. Вернитесь в приложение и нажмите «ОТКРЫТЬ МЕНЮ ПИТАНИЯ».
5. Выберите выключение/сон в появившемся системном меню.

Служба Accessibility нужна только для вызова системного меню. Приложение не читает содержимое экрана и не собирает данные.
